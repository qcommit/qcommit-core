# SDK provenance

`network.mjs` and `transport.mjs` are adapted from the local Quantum Seal Wallet SDK (MIT licensed). Their deployment-bytecode checks and fail-closed transaction confirmation are retained and extended for Qcommit launch configuration and explicit wallet signing. No legacy wallet private key, runtime ledger, or signing material is copied. The launch ABI and client are new Qcommit code. All source in this directory uses the repository MIT license.
